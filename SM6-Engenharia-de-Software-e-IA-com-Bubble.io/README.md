# SM6 - Engenharia de Software e IA com Bubble.io

## Descrição

Projeto desenvolvido como parte da disciplina de Engenharia de Software com Inteligência Artificial, utilizando a plataforma Bubble.io para criação de uma aplicação web funcional de forma prática e intuitiva.

O objetivo principal foi compreender como ferramentas de desenvolvimento visual e recursos de IA podem auxiliar na criação de sistemas modernos, responsivos e centrados na experiência do usuário.

## Metodologia

* Utilização da plataforma Bubble.io para desenvolvimento No-Code.
* Estruturação de páginas, componentes e fluxos de navegação.
* Aplicação de conceitos de Engenharia de Software.
* Uso de Inteligência Artificial como apoio ao desenvolvimento.
* Criação de interfaces focadas na experiência do usuário.

## Tecnologias e Ferramentas Utilizadas

* Bubble.io
* Inteligência Artificial
* Design UX/UI
* Engenharia de Software
* Modelagem de Fluxos
* Prototipagem Visual

## Objetivos

* Explorar o desenvolvimento de aplicações utilizando plataformas No-Code.
* Aplicar conceitos de Engenharia de Software em um projeto prático.
* Desenvolver uma interface intuitiva e funcional.
* Compreender como a IA pode auxiliar no processo de desenvolvimento.
* Criar fluxos de navegação e interação entre páginas.

## Funcionalidades Desenvolvidas

* Interface visual interativa.
* Navegação entre páginas.
* Componentes responsivos.
* Estrutura organizada de telas.
* Fluxos automatizados.
* Experiência otimizada para o usuário.

## Resultados

* Desenvolvimento de uma aplicação funcional utilizando Bubble.io.
* Aplicação prática dos conceitos estudados em sala de aula.
* Compreensão das possibilidades e limitações do desenvolvimento No-Code aliado à Inteligência Artificial.
