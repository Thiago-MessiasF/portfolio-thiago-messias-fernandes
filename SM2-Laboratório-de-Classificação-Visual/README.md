# SM2 - Laboratório de Classificação Visual

## Descrição

Projeto acadêmico utilizando o Teachable Machine para criar um modelo de visão computacional capaz de distinguir pessoas com e sem boné através da webcam.

## Metodologia

* Coleta de imagens para as categorias "com boné" e "sem boné".
* Treinamento do modelo utilizando a plataforma Teachable Machine.
* Testes em tempo real através da webcam para verificar a classificação das imagens.

## Considerações sobre Ética e IA

* **Análise de Viés:** Discussão sobre como a seleção restrita de dados de treinamento (apenas com/sem boné) pode gerar viés e limitar a capacidade de generalização do modelo.
* **Ação Mitigadora:** Aplicação do método *Human-in-the-loop* para revisão dos dados e ampliação da diversidade das amostras, considerando diferentes acessórios, condições de iluminação e ângulos.
