# SM3 - Batalha de Modelos e Engenharia de Prompt (XML)

## Descrição

Relatório de testes comparativos de engenharia de prompt estruturado em XML, avaliando a capacidade de diferentes LLMs (ChatGPT, Gemini, Claude, entre outros) em gerar páginas HTML/CSS Single Page para um site de apostas esportivas.

## Integrantes

* Pietra Rocha Gouveia
* Camila Serracine Peroni
* Thiago Messias Fernandes

## Foco dos Testes

* Qualidade do código gerado.
* Aderência à estrutura XML proposta.
* Organização do HTML e CSS.
* Responsividade da interface.
* Clareza e consistência dos resultados entre diferentes modelos.

## Resultados

* Comparação dos códigos gerados por cada LLM.
* Avaliação da capacidade de seguir instruções estruturadas em XML.
* Identificação de diferenças na organização, estilização e qualidade das páginas produzidas.
