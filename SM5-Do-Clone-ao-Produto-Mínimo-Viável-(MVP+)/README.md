# SM5 - Do Clone ao Produto Mínimo Viável (MVP+)

## Descrição

Desenvolvimento prático de um site moderno e responsivo utilizando metodologias avançadas de Engenharia de Prompt no Google AI Studio.

## Objetivos

* Demonstrar a transição do desenvolvedor de "executor técnico" para "definidor estratégico".
* Aplicar técnicas avançadas de Engenharia de Prompt no desenvolvimento web.
* Focar em pensamento sistêmico e validação de soluções geradas por IA.
* Transformar uma ideia inicial em um Produto Mínimo Viável (MVP).

## Metodologia

* Utilização do Google AI Studio para auxiliar no desenvolvimento.
* Criação e refinamento de prompts para geração de código.
* Validação e ajuste das soluções propostas pela IA.
* Desenvolvimento de uma interface moderna e responsiva.

## Resultados

* Desenvolvimento de um MVP funcional.
* Aplicação prática de Engenharia de Prompt no processo de desenvolvimento.
* Avaliação da colaboração entre desenvolvedor e Inteligência Artificial na criação de soluções digitais.
