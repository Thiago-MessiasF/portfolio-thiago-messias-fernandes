🏁 SM1 - A Corrida do Prompt
📖 Descrição

Este projeto apresenta experimentos de Engenharia de Prompt voltados para a interação com modelos de Inteligência Artificial, explorando técnicas de refinamento de instruções para geração de imagens e produção de textos formais.

O objetivo principal foi compreender como diferentes estruturas de prompts influenciam a qualidade, o contexto e a precisão dos resultados gerados pela IA.

🎯 Objetivos
Aplicar conceitos de Engenharia de Prompt.
Refinar instruções para geração de imagens com características específicas.
Desenvolver prompts para criação de textos formais e contextualizados.
Avaliar a influência da estrutura e detalhamento dos comandos nos resultados obtidos.
🛠️ Metodologia
Geração de Imagens

Foram realizados testes iterativos para aperfeiçoar a qualidade visual das imagens geradas, considerando aspectos como:

Estilo barroco;
Técnica de pintura a óleo;
Efeito de claro-escuro;
Textura de tela envelhecida;
Craquelado característico de pinturas antigas.
Produção de Textos

Foram elaborados prompts voltados para a criação de textos formais em diferentes contextos, incluindo:

E-mails profissionais;
Cartas históricas;
Comunicação institucional;
Narrativas contextualizadas.
📊 Resultados

Os experimentos demonstraram que o refinamento progressivo dos prompts contribui significativamente para:

Maior fidelidade visual nas imagens geradas;
Melhor adequação ao contexto solicitado;
Produção de textos mais coerentes e estruturados;
Redução de respostas genéricas da IA.
🚀 Tecnologias Utilizadas
ChatGPT
Engenharia de Prompt
Inteligência Artificial Generativa
