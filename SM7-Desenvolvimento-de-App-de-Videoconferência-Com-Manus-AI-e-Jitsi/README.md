# SM7 - Desenvolvimento de App de Videoconferência com Manus AI e Jitsi

## Descrição

Projeto voltado para o desenvolvimento de um aplicativo mobile de suporte técnico remoto utilizando videoconferência e ferramentas visuais integradas. A aplicação permite que técnicos orientem usuários de forma intuitiva através de chamadas de vídeo com recursos de anotação em tela.

## Objetivo

* Facilitar o suporte técnico remoto para usuários com pouca experiência tecnológica.
* Utilizar recursos visuais para tornar as instruções mais claras e eficientes.
* Explorar o desenvolvimento mobile com apoio de Inteligência Artificial.
* Integrar videoconferência e ferramentas de anotação em uma única aplicação.

## Tecnologias Utilizadas

* Manus AI
* Jitsi Meet
* React Native
* Expo
* TypeScript
* NativeWind
* React Native WebView

## Funcionalidades

* Criação e entrada em salas de suporte remoto.
* Videoconferência em tempo real.
* Compartilhamento de áudio e vídeo.
* Ferramentas de anotação em tela.
* Destaque de áreas utilizando círculos e retângulos.
* Desenho livre para orientações visuais.
* Indicador de toque para apontar elementos.
* Limpeza e desfazer anotações.
* Interface responsiva e intuitiva.

## Público-Alvo

* Técnicos de suporte.
* Usuários finais que necessitam de auxílio remoto.

## Benefícios

* Comunicação mais clara entre técnico e usuário.
* Redução de erros de interpretação.
* Maior eficiência no atendimento remoto.
* Melhor experiência para usuários com pouca familiaridade tecnológica.

## Resultados

* Desenvolvimento de uma aplicação funcional para suporte remoto.
* Integração bem-sucedida entre videoconferência e recursos visuais.
* Aplicação prática de conceitos de desenvolvimento mobile e Inteligência Artificial.
